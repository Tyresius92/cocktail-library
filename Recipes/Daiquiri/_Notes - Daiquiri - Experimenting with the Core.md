# Daiquiri: Experimenting with the Core

Rum comes in many styles; the Daiquiri is the best way to see how they interact with other ingredients. Three Daiquiris with exactly the same recipe but different rums, shaken at the same time (or in close succession so temperature and froth match).

## Cocktails
- [[Daiquiri (Light Rum)]]: bright fresh lime
- [[Daiquiri (Funky Rum)]]: grassy, vegetal, almost savory
- [[Daiquiri (Aged Rum)]]: rich peach and nectarine
